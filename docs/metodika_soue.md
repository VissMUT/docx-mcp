# Методика: электроакустический расчёт СОУЭ

Обязательная методика для запросов электроакустического расчёта системы оповещения и управления эвакуацией (СОУЭ). Следуй дословно, не импровизируй.

Форма выдачи: таблица + сноски 1–4.

Таблица (колонки строго):
«№ пом. | Наименование | S, м² | Габариты (L×W), м | L_Aeq, дБА | L_треб, дБА | R_max, м | L_расч, дБА | Запас, дБ | Кол-во ОП»

Методика (СП 3.13130.2026, действует с 01.06.2026, приказ МЧС №133 от 26.02.2026):

1. Способ оповещения — звуковой (табл. Б.1). Оповещатель настенный: УЗД ≥ 105 дБА на 1 м, 24 В; во взрывоопасных зонах — взрывозащищённое исполнение. Высота установки — 2,3 м (п. 6.18.1), расчётная высота — 1,5 м (п. 6.8.2), ΔH = 0,8 м. Запас на направленность и старение — +3 дБ.
2. L_треб = max(L_Aeq + 15; 65) дБА (п. 6.8.2). Не «68» (это 65 + запас — не дублировать запас).
3. L_расч = УЗД − 20·lg(R_max). R_max: 1 ОП на короткой стене — √(L² + (W/2)² + ΔH²); N ≥ 2 ОП по периметру — √((L/2)² + (W/2)² + ΔH²) (дальняя точка — геометрический центр).
4. Итог в сноске: всего ОП; условие L_расч ≥ L_треб выполнено во всех помещениях; макс УЗД ≤ 110 дБА (п. 6.8.4); падение напряжения ≤ 10 % (п. В.3.4).
5. При шуме L_Aeq > 85 дБА — УЗД ≥ 105 дБА в любой точке + обязательное световое и (или) тактильное оповещение (п. 6.8.2, абз. 3).
6. Уровни шума L_Aeq не выдумывать: брать по ТТ завода/данным об оборудовании; при отсутствии — принимать по аналогии с пометкой «допущение, подтвердить».
