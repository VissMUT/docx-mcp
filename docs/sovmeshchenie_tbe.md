# Инструкция: совмещение в томе ТБЭ

Обязательная процедура для запроса «совместиться в томе ТБЭ» (📐). Следуй дословно, не импровизируй.

Задача: привести разделы 3.7.5 и 12 тома ТБЭ (Раздел 10 по ПП РФ №87) в соответствие с фактическим составом систем по договору.

Правила: исходные данные — только стадия П (ссылки только на шифры томов П: ПТА, ИОС5; никаких РД/ОЛ/ТТ); мы — ведущий отдел (ОПСИТЗО), текст авторский; убрать отсутствующее (СКУД, диспетчеризация), добавить присутствующее (ВОЛС, ШБД, ЛВС); детализация — достаточно для экспертизы, без монтажных мелочей; нормативные ссылки сверить с перечнем.

Процедура:
1. Запросить том ТБЭ и тома-источники (ПТА, ИОС5).
2. Определить фактический состав: ОС, ВН, СС (ВОЛС/ШБД/ЛВС/IP-телефония), оповещение.
3. П. 3.7.5: заголовок под фактический состав; блок СС (топология ВОЛС/ШБД/ЛВС); актуализировать ОС/ВН/оповещение; скрытые проводки (слаботочные стояки, проходы через стены); ссылки на тома П; проверить ГОСТы в перечне нормативных ссылок.
4. Раздел 12: класс значимости, категория по СО; состав ИТСО только фактический; описание подсистем с ключевыми характеристиками; интеграция ОС+ВН+СС; электроснабжение и резервирование (ссылки на ИОС1); климатика и IP; кабели и прокладка; ссылка на ПТА.
5. Выдать: 1) заголовок; 2) сводка изменений; 3) полный текст; 4) чек-лист (параметр | исходные данные | текст | статус).
6. Финиш: проверить итоговый текст на случайные ссылки РД/ОЛ/ТТ — их быть не должно.

Структура ответа: Короткий вывод → 📋 Нормы → 🛠 Реализация → ⚠️ Риски → 📎 Смежные разделы
